## 👋 About this project

This repository is a structured Product Management teardown of **Sarvam AI**, built using a consistent PM framework — the kind of deep-dive you'd bring to a Product Manager / APM interview or portfolio review.

**Author:** Fresh graduate, IIIT Bhopal (CGPA 9.27) — built as part of a personal PM portfolio project.

**Why Sarvam AI?** It's a real, fast-moving Indian AI company that lets this case study cover generative AI, LLMs, Indian-language technology, developer platforms, enterprise AI, pricing, adoption, and responsible AI — all in one teardown, without repeating a "build an AI product from scratch" exercise.

> 📌 **Note on facts:** All company/product facts are sourced from Sarvam AI's official website, official docs (docs.sarvam.ai), and public press coverage as of **August 2026**, and are cited inline. Internal metrics, unpublished pricing, and confidential figures are never guessed — every such figure is explicitly labeled **"proposed"** or **"illustrative."**

## 🛠️ Methodology

- **Company facts:** sourced from sarvam.ai, docs.sarvam.ai, and public press coverage (cited within each section).
- **Personas, JTBD, funnel, metrics tree, RICE scores:** original PM analysis built for this case study — clearly labeled as proposed/illustrative, not internal company data.
- **Diagrams:** built with [Mermaid](https://mermaid.js.org/) so they render natively on GitHub — no external image hosting needed.
- **Prioritization framework:** RICE (Reach × Impact × Confidence ÷ Effort).
